# HMCL additional terms / HMCL 附加条款

Source: [HMCL English README, fixed commit 77eee17d361996259a48cc7896006a57d2e34a2a](https://github.com/HMCL-dev/HMCL/blob/77eee17d361996259a48cc7896006a57d2e34a2a/docs/README.md#license).

The upstream source-file headers grant GPL version 3 or, at your option, any later version. The full GPL version 3 text is in the root `LICENSE` (`LICENSE-HDSL.txt` in the Windows package). The README states the following additional terms under GPLv3 Section 7:

1. When you distribute a modified version of the software, you must change the software name or the version number in a reasonable way in order to distinguish it from the original version. (Under GPLv3, 7(c))
2. You must not remove the copyright declaration displayed in the software. (Under GPLv3, 7(b))

The two numbered terms above reproduce the upstream English terms. HDSL applies them to its HMCL-derived interface and keeps the upstream copyright visible in its license/about interface. The product name is HDSL; it is a modified product, not an official HMCL release.
